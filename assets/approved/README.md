The approved photo set was prepared in the ChatGPT conversation on 27 October 2026. Use the downloaded `MicroSprouts-approved-photo-assets.zip` to populate this directory.

**Upload steps**

1. Unzip the photo pack on your device.
2. Open this `assets/approved/` directory in GitHub, choose **Add file → Upload files**, and drag in the contents of the unzipped `assets/approved/` directory (nine `.webp` photos and `manifest.json`). Do not upload the ZIP itself.
3. Commit to `main`. Cloudflare will publish the images when the repository is deployed. The website will automatically use the new image set when it can successfully fetch the manifest and images.
